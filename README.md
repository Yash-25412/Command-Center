# Command Center

A personal workload and project command center. See `DEPLOY.md` for how to get this running at your own URL.

## What's in this first build (Stage 1)

- Real database persistence (Supabase/Postgres) — nothing is lost on refresh.
- Sign-in by email link, restrictable to one address.
- **Quick add**: type a task in plain language and it's created in under 10 seconds.
- **Inbox**: half-formed captures you can turn into a task or dismiss.
- **Work**: every task, grouped by status, filterable by Me / Team / a specific person.
- **Task detail**: next action, waiting-for, links, and the Journey — a running timeline of
  updates, meetings and decisions with full history.
- Your demo data: four projects, five team members, and a realistic spread of tasks.
